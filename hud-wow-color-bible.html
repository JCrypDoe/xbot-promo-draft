The 8-glyph color system

PlayerPowerID

WHO · Neon Violet · #BF00FF

Identity anchor

Defines who holds power within a given node. Every interaction in Earth3 traces back to a PlayerPowerID, the sovereign entity initiating or receiving value.

See it on the promo page

aDaB

WHAT · ADA Blue · #0057B8

Action / data block

Encodes what is being exchanged: asset type, data payload, or contract action. aDaB is the content layer of every node transaction.

See it on the promo page

moMintNTime

WHEN · Ghost Grey · #B0B0B0

Temporal marker

Records the moment of mint, event trigger, or timestamp. Ghost Grey signals neutral, non-urgent structural data: the clock of the system.

See it on the promo page

TimeChain/Rails

THEN · Deep Grey · #3A3A3A

Sequence logic

Defines the ordered chain of consequence: what happens after a condition is met. Deep Grey denotes scaffolding and infrastructure-level logic.

See it on the promo page

GXYZ

WHERE · Money Green · #00A550

Spatial coordinate

Anchors a geographic or grid-based address within the Earth3 map layer. Money Green signals value-bearing location data.

See it on the promo page

CowsCome4Dayz

WHY · Sunset Orange · #FF6200

Motivation layer

Encodes the incentive, reward rationale, and player reason-to-engage. Sunset Orange is the energy that drives participation.

See it on the promo page

PayTooPlay

HOW · Electric Green · #39FF14

Mechanism / payment rail

Defines the payment rail, execution method, and transactional pathway. Electric Green is high-visibility by design: it marks the action trigger.

See it on the promo page

HUD-WoW

VOID · Black · #000000

Null / overlay state

Displayed when a field is empty, inactive, or rendering a HUD overlay. VOID is structural silence: the absence of assignment.

See it on the promo page

Start with the brief

Animation rules (web only)

  • Entry: glyphs fade in from 0 to 100% opacity, staggered 150ms per glyph.
  • Hover: glyph border pulses in its field color (box-shadow glow).
  • CTA idle: Electric Green outer glow, 2s loop.
  • VOID / HUD-WoW: never animates, including on hover.
  • Animation is skipped for visitors who set reduced motion. Print and static exports are unaffected.

Quick reference

Usage notes

  • Never swap color assignments between fields.
  • VOID black is for null, empty, or overlay states only, never decoration.
  • Electric Green is an accent or CTA color. Overuse weakens the signal.
  • Ghost Grey and Deep Grey are structural: scaffolding, timestamps, metadata.
  • Validate every text-on-color pairing against WCAG 2.1 AA before public release. ADA Blue and Deep Grey need particular care on dark backgrounds.
