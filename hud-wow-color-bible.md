# HUD-WoW Color Bible (Working Draft)

Canonical signal mapping for Earth3 mint UX.

- **Midnight Violet** → Privacy
- **Cardano Blue** → Cardano blockchain / "Rules of the Game"
- **Grey Matter** → Smart contract logic (binding layer)
- **Bleed Lime Green** → GXYZ logic (TimeChain energy)
- **TimeChain Black** → TimeChain base layer/foundation
- **ZK White** → Helixbox + meshX + ZK proof network
- **Sunrise** → PlayerPower + Bitcoin side of Earth3
