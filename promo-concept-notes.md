# Earth3 Promo Concept Notes (Doc-Grounded)

This note maps language from the new docs into practical promo scenario structure for the **Why be an Xbot?** flow.

## Core concept anchors pulled from docs

- **Xbot value pitch**: player-owned identity, moments, and programmable rights.
- **aDaB framing**: value-preserving economy intent (ADA/BTC-backed narrative).
- **PlayerPower**: citizens gain influence/utility over time through contribution.
- **moMintNTime**: verified moments become durable, usable records.
- **AI OS / agent-first operation**: the system executes routine intent safely with fewer repeated approvals.
- **Smart-contract Remix lineage + Royalty logic**: every action/event can become a reusable Lego-like contract object with clear payout rules.

## Smart-contract framing for promo

Use each promo sample as a small contract object:

- **Who**: player/agent/org identity
- **What**: event/action/asset or intent-bundle
- **When**: activation window (or `now`)
- **Where**: runtime surface (broadcast, rights-graph, sim-runtime, etc.)
- **Why**: utility + rights objective

Then route to:

- discovery and verification,
- permissioned remix and derivative flow,
- reward or revenue logic.

## New sample groups to test

- **AI OS Autopilot Lane**: routine intent execution with auditability.
- **PayTooPlay Event Loop**: paid participation with payout loops.
- **PlayerPower Rank/Pool flows**: influence and reward progression.
- **moMintNTime Streak/Glyph proofs**: temporal progression mints.
- **Citizen NFT governance pass**: baseline governance rights.
- **Frontier Agent Remix license**: trusted agent derivative operations.
