HUD-WoW Details

Void Black interface · Customizable player alerts

HUD-WoW is the player-facing signal layer. In quiet mode it stays Void Black. When verified moments and outcomes matter, it lights up with the minimum signal you need to act fast.

Where WHEN and THEN Interact

WHEN gives the verified moment. THEN gives the outcome rails. HUD-WoW is where those two become a glanceable decision for the player.

Core interaction

  • WHEN signal: a moMintNTime is active, recent, or scheduled.
  • THEN signal: outcome path is available (reward, route, claim, unlock, or next task).
  • VOID state: interface goes quiet when nothing requires attention.

Customizable alerts for players

  • Choose source scope: friends, follows, sponsors, NodeRunners, or all.
  • Choose alert types: mint events, payout chances, quest windows, privacy requests.
  • Choose urgency behavior: silent, soft pulse, high-priority stack.
  • Choose visibility: lock-screen style badge only, or full preview card.
Simple takeaway:

Void Black keeps noise down. WHEN + THEN highlights only what matters, when it matters.
